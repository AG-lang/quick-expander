# ⚡ Quick Expander (全局文本快速补全与扩展神器)

**Quick Expander** 是专为 Windows 设计的高性能系统级文本扩展与自动补全工具。无论您身处电脑的哪个角落（**记事本、浏览器、微信、QQ、Word、Excel、VS Code、PowerShell / CMD 等任意输入框**），输入设定的前缀触发词（如 `411`），系统均能瞬间自动擦除并扩展为您预设的目标文本（如 `4113293000`）。

---

## 🌟 核心特性

1. **全系统无缝生效 (OS-Wide)**：
   - 基于 Windows 底层按键拦截与智能注入机制，支持整台电脑任何应用程序与输入环境。
2. **即时极速补全 (Zero Latency)**：
   - 输入预设触发词（如 `411`）的最后一个字符时，自动毫秒级退格并替换为目标文本（如 `4113293000`）。
3. **多候选项光标悬浮选单 (Feature 5)**：
   - 当某触发词仅对应 1 条规则时保持**瞬间直接上屏**。
   - 当同一个触发词设置了多条不同的规则时（例如 `411` 对应两家不同公司的编码），光标旁自动浮现半透明精致悬浮选单，按数字键 `1` ~ `9` 或鼠标点击瞬间选中上屏！按 `Esc` 自动退出。
4. **规则分类与标签树 (Feature 6)**：
   - 支持按【快捷编码】、【个人信息】、【工作模版】、【动态宏】等分类归纳，支持自定义新建分类、重命名与删除。
   - 左侧分类导航栏支持一键切换筛选，并展示各自分类的规则数量徽标。
5. **支持任意字符与长文本**：
   - 支持纯数字、纯字母、中文、特殊符号、多行段落、代码片段、Emoji 表情等。
6. **动态宏变量支持 (Dynamic Placeholders)**：
   - `{{date}}`：当前日期（例如 `2026-08-27`）
   - `{{time}}`：当前时间（例如 `14:30:00`）
   - `{{datetime}}`：完整日期与时间
   - `{{weekday}}`：当前星期（例如 `星期四`）
   - `{{clipboard}}`：实时插入当前剪贴板文本
   - `{{uuid}}`：生成随机 36 位 UUID
   - `{{cursor}}`：设置补全后光标自动定位的落点
7. **双模式文本注入 (SendInput + Clipboard)**：
   - 单行短文本采用原生 Win32 Unicode 按键模拟（不占用用户剪贴板）。
   - 多行复杂长文本自动启用闪电剪贴板粘贴（毫秒级切换并自动恢复原有剪贴板）。
8. **现代化 PyQt6 图形管理界面**：
   - 规则增删改查、关键字快速搜索过滤、开启/禁用单条规则。
   - **内置即时测试沙盒**：直接在界面中打字体验补全效果。
   - JSON / CSV 格式一键导入与导出备份。
9. **系统托盘与全局热键**：
   - 支持最小化到 Windows 右下角托盘静默运行。
   - 默认全局热键 `Ctrl+Alt+S` 一键暂停/恢复扩展功能（伴随气泡提醒与声音反馈）。
   - 一键开启/关闭“开机自动启动”。

## 📁 预设内置规则示例

| 触发词 (Trigger) | 替换结果 (Replacement)         | 说明               | 所属分类    |
| :------------ | :------------------------- | :--------------- | :------ |
| **`411`**     | `4113293000`               | 快捷编号补全 (用户定制示例)  | 🔢 快捷编码 |
| **`@@em`**    | `myemail@company.com`      | 常用工作邮箱           | 👤 个人信息 |
| **`@@phone`** | `13800138000`              | 常用手机号码           | 👤 个人信息 |
| **`@@addr`**  | `北京市海淀区中关村南大街1号`           | 常用收货地址           | 👤 个人信息 |
| **`//date`**  | `{{date}}` (如 2026-08-27)  | 快速插入当前日期         | ⏰ 动态宏   |
| **`//time`**  | `{{time}}` (如 14:30:00)    | 快速插入当前时间         | ⏰ 动态宏   |
| **`//now`**   | `{{datetime}} {{weekday}}` | 快速插入日期时间及星期      | ⏰ 动态宏   |
| **`//uuid`**  | `{{uuid}}`                 | 生成随机 UUID4 唯一标识码 | ⏰ 动态宏   |

## 💡 多候选项与分类使用技巧

1. **为同一个触发词设置多个候选**：
   - 点击【新增规则】，触发词输入 `411`，替换内容输入 `4118888888`，说明填写“VIP专号”。
   - 在任意文本框或沙盒中输入 `411`，系统将在光标旁浮现：
     - `[1] 4113293000 (快捷编号补全)`
     - `[2] 4118888888 (VIP专号)`
   - 此时直接按下数字键 `1` 或 `2`，即可精准输入对应的目标文本！
2. **分类管理**：
   - 点击左侧【➕ 新建分类】可随时创建新标签（如“财务账户”、“客服话术”）。
   - 右键点击分类项，可进行【重命名】或【删除】。
